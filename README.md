# Тестирование

## Установка через Poetry фреймворк Pytest и Code Coverage
1. Введите в терминале команду:
~~~
poetry add --group dev pytest
~~~

2. Запустите тесты с помощью команды pytest.
Веедите в терминале команду:
~~~
pytest
~~~

3. В pytest для анализа покрытия кода надо поставить библиотеку 
pytest-cov:
Веедите в терминале команду:
~~~
poetry add --group dev pytest-cov
~~~

4. Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:
~~~
pytest --cov
~~~
 — при активированном виртуальном окружении.

5. В файле conftest.py находятся фикстуры - своего рода ячейки с данными, которые  
используются в файлах для тестов (файлах расположенных в папке tests с префиксом test_)

6. Чтобы сформировать отчёт о покрытии, можно ввести команду в терминале:
~~~
pytest --cov=src --cov-report=html
~~~

Отчет о покрытии в HTML-формате находится в папке htmlcov
 и храниться в файле с названием index.html.
Открывать данный отчёт необходимо с помощью браузера (Open In -> Browser).

### Описание проекта
Проект предназначен для сбора данных о самолетах в воздушном пространстве заданной страны с использованием внешних API.

### Структура модулей
src/api/
base_api.py - абстрактный базовый класс для работы с API

aeroplanes_api.py - класс для работы с API Nominatim (получение координат стран) и OpenSky (получение данных о самолетах)

src/models/
aeroplane.py - класс для представления информации о самолете (позывной, страна регистрации, скорость, высота). Содержит валидацию данных и методы преобразования из ответа API.

src/file_handlers/
base_saver.py - абстрактный класс для работы с хранилищем данных

json_saver.py - класс для сохранения и загрузки данных о самолетах в JSON-файл

src/utils/
filters.py - утилиты для фильтрации, сортировки и вывода данных о самолетах

tests/
Модульные тесты для всех компонентов проекта

### Запуск

```
# Установка зависимостей
pip install -r requirements.txt

# Запуск программы
python main.py
```
### Использование
1.После запуска программы необходимо:

2.Ввести название страны (например, Russia, Canada, Germany)

3.Дождаться загрузки данных о самолетах

4.Указать количество самолетов для вывода в топ N

5.При необходимости задать фильтры по стране регистрации и диапазону высот
